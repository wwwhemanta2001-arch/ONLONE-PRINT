DR QR SE PRINT — Website files
=================================

ফাইল:
- index.html : সম্পূর্ণ website (HTML + CSS + JavaScript)
- README_BN.txt : বাংলায় ব্যবহার ও প্রকাশের নির্দেশিকা

কম্পিউটারে preview:
1. ZIP ফাইলটি Extract করুন।
2. DR_QR_Se_Print_Website ফোল্ডারে যান।
3. index.html-এ double-click করুন। Chrome বা Edge-এ খুলবে।

প্রকাশের আগে index.html-এ পরিবর্তন করুন:
1. WHATSAPP_NUMBER খুঁজে "919999999999" বদলে নিজের WhatsApp নম্বর দিন।
   ভারতের উদাহরণ: 919876543210 — country code সহ, + বা space ছাড়া।
2. ঠিকানার placeholder, ব্যবসার সময়, ফোন নম্বর এবং পরিষেবার তথ্য নিজের মতো বদলান।
3. আপনার দোকানে বাস্তবে যে পরিষেবা আছে শুধু সেগুলিই রাখুন।
4. দাম, delivery/pickup, turnaround time এবং privacy notice যোগ করুন।

বিনামূল্যে GitHub Pages-এ প্রকাশ:
1. https://github.com/ এ account তৈরি বা লগইন করুন।
2. New repository-তে গিয়ে repository name দিন: dr-qr-se-print
3. Public repository নির্বাচন করে Create repository করুন।
4. Add file → Upload files নির্বাচন করুন।
5. এই ZIP থেকে Extract করা index.html ফাইলটি upload করুন (README ঐচ্ছিক)।
6. Commit changes চাপুন।
7. Repository → Settings → Pages-এ যান।
8. Build and deployment-এর Source-এ Deploy from a branch বেছে নিন।
9. Branch: main এবং folder: /(root) নির্বাচন করে Save করুন।
10. কিছুক্ষণ পরে Pages অংশে যে URL দেখাবে সেটি খুলুন। URL সাধারণত:
    https://YOUR-USERNAME.github.io/dr-qr-se-print/

বিকল্প: Netlify Drop
- https://app.netlify.com/drop খুলে index.html-সহ extracted folder drop করুন।
- Netlify-র বর্তমান account ও publishing conditions অনুসরণ করুন।

নিজস্ব QR code:
- Website publish হওয়ার পর live URL কপি করুন।
- সেই URL দিয়ে একটি QR code তৈরি করুন এবং অন্য ফোনে scan করে পরীক্ষা করুন।
- URL নিশ্চিত হওয়ার আগে QR code প্রিন্ট করবেন না।

সীমাবদ্ধতা:
- এটি front-end static website; database, admin panel, customer login, file upload, payment gateway বা live order tracking নেই।
- Enquiry form WhatsApp message তৈরি করে; WhatsApp নম্বর সেট না করলে কাজ করবে না।
- এই site নিজে কোনো অর্ডার পাঠায় বা প্রিন্ট করে না; এটি যোগাযোগের মাধ্যম।
- কাস্টম .com domain সাধারণত আলাদা খরচের। Free hosting provider-এর শর্ত প্রযোজ্য।
